# 노션 연결하기

처음 한 번만 하면 되는 작업입니다. 15분쯤 걸립니다.

## 1. 통합(Integration) 만들기

1. <https://www.notion.so/my-integrations> 접속 → **New integration**
2. 이름은 아무거나(예: `Story of the Light`), 워크스페이스를 고릅니다.
3. Capabilities는 **Read content**만 켜면 충분합니다.
4. 발급된 **Internal Integration Secret**을 복사합니다. → `NOTION_TOKEN`

## 2. 데이터베이스 두 개 만들기

노션에서 새 페이지를 만들고 `/database` → **Table view**를 두 개 만듭니다.
속성 이름은 README의 표대로 **한 글자도 다르지 않게** 맞춰 주세요. 매퍼가 이름으로 찾습니다.

### 게시물 DB 속성

`제목`(제목) · `탭`(다중 선택) · `카테고리`(선택) · `관련 캐릭터`(다중 선택) · `요약`(텍스트) · `날짜`(날짜) · `태그`(다중 선택) · `이미지`(파일) · `정렬`(숫자) · `공개`(체크박스)

`탭` 옵션은 `src/config/tabs.ts`의 `label`과 같아야 합니다.
→ `서리화` `아젬` `상서고` `로렌티` `모험가 소대` `세계`

`관련 캐릭터` 옵션은 `src/config/characters.ts`의 키와 같아야 합니다.
→ `서리화` `야슈톨라` `카르네아데스` `로레트` `이스노티` `그레틴` `모험가 소대`

### 연표 DB 속성

`내용`(제목) · `시기`(선택) · `관련 캐릭터`(다중 선택) · `순서`(숫자, 선택 사항)

`시기` 옵션 예시: `-10년` `-5년` `-1년` `신생` `창천` `홍련` `칠흑` `효월` `황금` `백은`

## 3. 통합을 DB에 초대하기

각 DB 페이지 오른쪽 위 **···** → **Connections** → 1단계에서 만든 통합을 선택합니다.
이걸 빼먹으면 빌드가 빈 결과를 받아 옵니다. 가장 흔한 실수예요.

## 4. DB ID 찾기

DB를 전체 페이지로 연 뒤 주소창을 봅니다.

```
https://www.notion.so/워크스페이스/1a2b3c4d5e6f7890abcdef1234567890?v=...
                                  └──────── 이 32자리가 DB ID ────────┘
```

`?v=` 앞까지가 DB ID입니다. 하이픈은 있어도 없어도 됩니다.

## 5. 로컬에 넣기

```bash
cp .env.example .env
```

```env
NOTION_TOKEN=secret_...
NOTION_POSTS_DB=1a2b3c4d5e6f7890abcdef1234567890
NOTION_TIMELINE_DB=0f9e8d7c6b5a43210fedcba987654321
```

```bash
npm run build
```

콘솔에 `[content] 게시물 N건을 불러왔습니다.`가 뜨면 성공입니다.

## 잘 안 될 때

**`[content] NOTION_TOKEN 이 없어 샘플 데이터로 렌더링합니다.`**
`.env` 파일이 프로젝트 루트에 있는지, 변수 이름 철자가 맞는지 확인하세요.

**글이 0건으로 나옴**
3단계(Connections 초대)를 건너뛴 경우가 대부분입니다. 그다음으로 흔한 건 `공개` 체크박스가 꺼져 있는 경우입니다.

**글은 뜨는데 엉뚱한 탭에 있음**
노션 `탭` 옵션 이름과 `tabs.ts`의 `label`이 다릅니다. 공백이나 가운뎃점까지 똑같아야 합니다.

**배지가 회색으로만 나옴**
`관련 캐릭터` 옵션 이름이 `characters.ts`의 키와 다릅니다. 매칭 실패 시 회색으로 대체됩니다.

**이미지가 안 보임**
노션 파일 URL은 약 1시간 뒤 만료됩니다. 그래서 빌드할 때 `public/notion-assets/`로 내려받아 고정합니다. 실패하면 콘솔에 `[images] 내려받기 실패` 경고가 찍히니 그 URL을 확인하세요. 이 폴더는 `.gitignore`에 있으니 커밋할 필요 없습니다.

**GitHub Pages에서 CSS가 깨짐**
`astro.config.mjs`의 `base`가 저장소 이름과 다릅니다.
