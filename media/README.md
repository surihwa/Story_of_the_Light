# 이미지 폴더

Screenshots 와 Gallery 는 노션이 아니라 **이 폴더의 파일**을 읽습니다.
파일을 넣고 커밋해서 푸시하면 다음 배포에 반영됩니다.

## 어디에 넣나요

```
media/
├── screenshots/
│   ├── surihwa/          ← 서리화 탭에 뜹니다
│   ├── frost_library/    ← 상서고 탭
│   └── world/            ← 세계 탭
└── gallery/
    └── (같은 구조)
```

폴더 이름은 **중분류의 주소 이름**과 같습니다.

| 폴더 이름 | 탭 |
|---|---|
| `surihwa` | 서리화 |
| `azem` | 아젬 |
| `laurette` | 로레트 모린 |
| `isnotti` | 이스노티 헤멜 |
| `frost_library` | 상서고 |
| `laurentti` | 로렌티 |
| `scholasticate` | 신학원 |
| `maelstrom` | 흑와단 |
| `world` | 세계 |

어느 폴더에도 넣지 않고 `screenshots/` 바로 아래에 두면 `세계` 탭에 뜹니다.
같은 사진을 두 탭에 올리고 싶으면 양쪽 폴더에 복사해 넣으면 됩니다.

## 파일 이름 규칙

`번호_설명.확장자` 형태입니다. 둘 다 생략할 수 있습니다.

| 파일 이름 | 번호 | 화면에 뜨는 설명 |
|---|---|---|
| `012_눈 내리는 쿠르잔.jpg` | 12 | 눈 내리는 쿠르잔 |
| `012.jpg` | 12 | (없음) |
| `눈 내리는 쿠르잔.jpg` | — | 눈 내리는 쿠르잔 |

**번호가 큰 것이 위에 옵니다.** 번호가 없는 파일은 이름 역순으로 그 뒤에 붙습니다.
`001` 처럼 0을 채워 두면 10번을 넘어가도 순서가 흐트러지지 않습니다.

지원 형식: `.jpg` `.jpeg` `.png` `.gif` `.webp` `.avif`

## 용량

원본을 그대로 넣어도 됩니다. 빌드할 때 `scripts/build-media.mjs` 가
카드용(400·800px 정사각)과 확대용(가로 1600px, 원본 비율) WebP 를 만들어 내보내고,
**원본은 배포되는 사이트에 들어가지 않습니다.**

목록은 정사각형 칸으로 보여 주므로 **가운데를 기준으로 잘립니다.**
잘리면 곤란한 그림은 미리 정사각형으로 맞춰서 넣으세요.
칸을 눌러 크게 볼 때는 잘리지 않은 전체 그림이 뜹니다.

한 번 변환한 파일은 다시 만들지 않으니, 사진을 추가해도 빌드가 느려지지 않습니다.
파일을 지우면 딸린 변환본도 함께 정리됩니다.

다만 **원본은 저장소에 그대로 쌓입니다.** 깃허브는 저장소 1GB 정도를 권장하니,
4K 스크린샷을 수백 장 올릴 계획이라면 미리 적당한 크기(예: 가로 2560px)로 줄여서 넣는 편이 좋습니다.

## 올리는 방법

1. 이 폴더의 알맞은 자리에 파일을 넣습니다.
2. 커밋하고 푸시합니다.
3. 깃허브 액션이 알아서 변환하고 배포합니다.

깃허브 웹사이트에서 폴더를 열고 **Add file → Upload files** 로 끌어다 놓아도 됩니다.
터미널을 쓰지 않아도 됩니다.
